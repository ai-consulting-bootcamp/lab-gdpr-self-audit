## Project audited

*Previously On: Love Is Blind* is an autonomous research and recap agent
that creates spoiler-aware recaps using entertainment metadata, public
web sources and fan reactions.

The main GDPR question identified in the audit is not the viewer-facing
recap itself, but the secondary processing of **public third-party
content, particularly YouTube comments**, through an AI/RAG pipeline.

## Bottom-line recommendation

**Proceed with conditions.**

Before production, the project should minimise YouTube-comment data,
establish and document the lawful basis for public-source processing,
verify DPAs/international-transfer configurations across vendors, define
retention, and implement data-subject-rights workflows.

> This is a first-pass educational compliance assessment, not legal
> advice, a DPIA, or a certification.
