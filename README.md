Submission for this lab. Everything below is scoped to this lab only.

## File map

- `instructions.md` — the lab instructions (unchanged)
- `rubric.md` — the grading rubric (unchanged)
- `data_processing_brief.md` — kick-off section, what data the system processes, source, purpose, storage, decision impact

## Workflow

1. Fork this repository.
2. Add the files above to the fork.
3. Open a pull request back into this repository.
4. The AI reviewer checks the PR against `rubric.md` and leaves feedback.
